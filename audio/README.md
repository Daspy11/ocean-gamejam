Retro effects use [JSFXR](https://github.com/chr15m/jsfxr), installed as a development dependency. Each effect has its own `audio/sfx/<name>/` folder containing `preset.json` (editable source) and `sound.wav` (generated playback file). Run `npm run sfx` after editing presets. The generator renders all sound folders; Phaser plays the resulting WAVs using the `SFX` manifest in `src/assets.ts`.

`audio/sfx/powerup/` is a rising square-wave charge lasting about 2.2 seconds. It starts after Walter's “i'm,” builds through the one-second zoom and 1.2-second shake, then stops as he reaches full white and bursts into stars. The existing chime plays at that boundary, using the close-up's simulation timestamp. It pauses with the scene and clears on mute, world replacement, or shutdown. Rebuild with `npm run sfx -- powerup`.

`audio/sfx/chime/` is a bright square-wave coin pickup, about 143 ms long. It starts higher and jumps just over an octave after roughly 36 ms, with a slight upward pitch slide and a quick decay. It plays for title/inventory/dialogue-choice selection, settings opening/closing/navigation/toggles, inventory opening/closing and successful item use, and player placement of decorations or salt on the home island. Orb boiling completion uses it when the new salt joins home. Off-island placement keeps the tok. `world.chimeCue` records sim cues; if both cue counters change in one frame, the chime replaces the tok. Settings and title call `playChime` directly because they run without an active world scene. Rebuild only this sound with `npm run sfx -- chime`; named folders leave the other WAVs untouched.

`audio/sfx/interact/preset.json` is a short square-wave “tok” with a small downward pitch slide, no noise, no arpeggio, and no repeat. It replaces the earlier noisy clunk. The output is about 71 ms, mono, 44.1 kHz, 16-bit PCM. `sfx/interact` now covers item handling, inspections, placement, and inventory/choice controls; see the assignments in `SFX-REVIEW.md`. The simulation increments optional `world.interactCue`, and `hearWorld` plays at most one cue per frame, coalescing chest contents/reward boxes and other simultaneous changes. Mute, audio lock, pause, and world loads discard missed cues rather than replaying them later.

Presets use JSFXR's native JSON format, so they can be pasted into the serialized sound field at [sfxr.me](https://sfxr.me) to hear and adjust with sliders, then serialized back into `preset.json`. For the interaction sound, `p_base_freq` changes pitch, `p_freq_ramp` changes the pitch slide (negative falls), `p_env_sustain` and `p_env_decay` change length, `p_duty` changes the square-wave character, and `sound_vol` changes level. These are normalized synth controls, not Hz or seconds. Keep all preset fields when exporting, including `sample_rate` and `sample_size`.

To add a sound, copy the interaction folder, edit its preset, run `npm run sfx`, and add one `SFX` manifest entry pointing at its WAV. The synth stays out of the browser bundle. JSFXR's library licence is included in `node_modules/jsfxr/UNLICENSE`.
